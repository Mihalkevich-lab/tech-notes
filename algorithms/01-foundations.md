## 1. Бинарный поиск
Это алгоритм, который ищет элементы только на отсортированном массиве и каждый раз делит его пополам. Из-за того, что бинарный поиск отсекает половину неподходящих вариантов, время его выполнения происходит за $\log_2(n)$

## Сортировка выбором

### Массивы и списки
Когда вам надо сохранить несколько элементов в памяти компьютера, это можно сделать двумя основными способами: воспользоваться массивом или связанным списком.<br/>

**Массив** -- элементы следуют строго по порядку. Они хранятся в памяти непрерывно. <br/>
**Список** -- элементы размещаются где угодно в памяти. Каждый элемент знает адрес следующего за ним.
<br/>

Операция | Массив (Array) | Связанный список (Linked List) |
| :--- | :--- | :--- |
| **Чтение** | **\(O(1)\)** (Мгновенно по индексу) | **\(O(N)\)** (Нужно перебирать всю цепочку с начала) |
| **Вставка** | **\(O(N)\)** (Медленно, нужно сдвигать элементы в RAM) | **\(O(1)\)** (Мгновенно, просто меняем адрес-указатель) |
| **Удаление** | **\(O(N)\)** (Медленно, нужно сдвигать элементы назад) | **\(O(1)\)** (Мгновенно, перенаправляем указатель в обход) |

существуют так же гибридные структуры данных. Например, массив + связанный список. в каждом элементе массива находится собственный связанный список.

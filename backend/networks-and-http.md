# Основы Бэкенда: Сети и Протокол HTTP 🌐

Бэкенд-разработка — это управление данными и логикой, которая скрыта от пользователя. Всё взаимодействие между клиентом (браузером) и сервером строится на сетевых протоколах.

---

## 1. Как устроен сетевой запрос?

Когда пользователь вводит адрес сайта, происходит обмен данными по модели **Клиент-Сервер**:
1. **Клиент (Браузер)** отправляет **HTTP-запрос** (Request).
2. **Сервер (Бэкенд)** обрабатывает его и возвращает **HTTP-ответ** (Response).

---

## 2. Структура HTTP-запроса

Каждый запрос к бэкенду содержит три важные части:

*   **Стартовая строка:** Метод запроса (что делаем) + URL (куда обращаемся).
*   **Заголовки (Headers):** Служебная информация (какой браузер, какой тип данных принимаем).
*   **Тело (Body):** Сами данные (например, логин и пароль при авторизации).

### Основные HTTP-методы:
*   `GET` — Получить данные (без тела запроса, параметры видны в URL).
*   `POST` — Отправить/создать новые данные (данные скрыты в Body).
*   `PUT` / `PATCH` — Обновить существующие данные.
*   `DELETE` — Удалить данные.

---

## 3. Файлы Cookie (Куки) 🍪

**Куки** — это маленькие текстовые файлы, которые сервер отправляет браузеру для сохранения состояния.

*   **Зачем нужны:** HTTP — это протокол *stateless* (сервер не помнит предыдущие запросы). Чтобы сайт «узнал» вас при переходе на новую страницу, используются куки.
*   **Как это работает:**
    1. Вы авторизуетесь на сервере.
    2. Сервер присылает заголовок `Set-Cookie: session_id=abc123`.
    3. Браузер сохраняет этот файл и автоматически прикрепляет его к *каждому* следующему запросу на этот сайт.

---

## 4. Коды ответов сервера (Status Codes)

Бэкенд всегда возвращает цифровой код, показывающий результат работы:

| Код | Что значит | Пример |
| :--- | :--- | :--- |
| **2xx** | Успешно | `200 OK` (Все прошло отлично) |
| **3xx** | Перенаправление | `301 Moved Permanently` (Страница переехала) |
| **4xx** | Ошибка Клиента | `404 Not Found` (Страница не найдена) |
| **5xx** | Ошибка Сервера | `500 Internal Server Error` (Упал бэкенд-код) |
